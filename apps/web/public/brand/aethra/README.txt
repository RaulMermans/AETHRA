AETHRA / LOGO KIT v1.0
======================

SOURCE
- 01_Original_Primary_Navy.png is the original uploaded image, pixel-for-pixel unchanged.
- All other variations were composed directly from the uploaded bitmap; the A silhouette, orbital swoosh, star, and AETHRA letterforms were not redrawn or AI-regenerated.
- Transparent PNGs are extracted from the navy background. Because the source is a flattened PNG, fine anti-aliasing edges may differ slightly against very light backgrounds.
- Light-background versions change white letterforms to deep navy for legibility and retain cyan/orange highlights.
- Monochrome files recolor the existing shapes, not their geometry.

CONTENTS
- PNG/ : 25 named image versions (primary, transparent, light, mono, icon, stacked, wordmark).
- Favicons/ : favicon.ico (16–256 px) and square PNG icons in common device sizes.

PREFERRED USAGE
- Primary brand lockup: PNG/01_Original_Primary_Navy.png.
- Website over dark backgrounds: PNG/03_Full_Color_Transparent.png.
- Website over white: PNG/04_Full_Color_Light.png.
- Small avatar: PNG/22_App_Icon_Navy_1024.png.
- Tiny favicon: Favicons/favicon.ico.

LIMITATIONS
- These are raster images, not a native editable vector (SVG/AI/EPS). A genuine vector master would need manual tracing or the original design file.
- Do not stretch, squash, change letter spacing, or distort the icon.
